# 从统计初稿写到自己的文章

先通读生成的 HTML，核对图和数字。然后把整个结果目录复制到 `private/manuscript/`，在副本里修改。保留 `latex/` 和 `figures/` 的相对位置，避免下次运行分析覆盖手工改稿。

## 从哪里改

| 想改的内容 | 文件或设置 |
|---|---|
| 署名、纪念日、城市、喜好、配色 | `config.local.json`，修改后重新分析 |
| 这一次的中文正文和图注 | 稿件副本中的 `latex/report_zh.tex` |
| 这一次的英文正文和图注 | 稿件副本中的 `latex/report_en.tex` |
| 浏览器版本的文字 | 稿件副本中的 `report_zh.html` / `report_en.html` |
| 每次自动生成的结果段落 | 源码 `src/naturelove/report.py` 的 `sections()` |
| 所有报告的版式 | 源码 `src/naturelove/templates/report.tex.j2`、`report.html.j2`、`report.css` |
| 图的坐标、字号和布局 | 源码 `src/naturelove/figures.py` |

HTML 与 LaTeX 是分别生成的文件，手工修改一份不会同步到另一份。改源码后要在项目根目录重新执行 `python -m pip install .`，再重新生成；只改本次稿件时不用重新安装。

## 写之前，补一条时间线

记下第一条记录的日期、确认关系的日期，以及双方确认过的重要节点。接着补上会影响聊天方式的背景：比如考试周、工作变化、见面或共同生活。只填确定的事，拿不准的留空。

把导出窗口和关系时间线分开。导出从一月开始，不一定是一月才认识；某月消息少，也可能是那个月的历史没有导全。方法部分需要说明这次实际观察了哪一段。

## 结果段落怎么展开

按“聊天量 → 时段 → 参与方式 → 表达与渠道 → 词汇”展开，通常比按图号逐项复述更顺。

每段先说明在比较什么，再给关键数字和图号，最后说明这一比较回答了什么。例如 Figure 3 同时给出消息、字符和回合：如果一方发的消息更多，但回合数接近，可以接着讨论每回合条数，而不只停在消息总量上。

写到时间变化时，先看 Figure 1 的观察日期和分母，再看 Figure 2 的时段分布。可以结合双方确认的生活背景解释变化，把统计观察与补充经历各自说清楚。

Figure 6 的话题来自配置词典。一条消息可命中多个类别，读者需要同时知道覆盖了多少正文。Figure 7 的阴影是等量抽样得到的敏感性范围，图注中写清抽样条数与次数；虚词匹配使用的是小型示例词典。

## 图注写什么

一张图的图注至少说明：统计了谁、什么时间段、单位和分母，以及读图需要的定义。多面板图按 A、B、C、D 依次解释。

以互动图为例，可以按下面的顺序写，具体数字从自己的结果里填：

> Figure 3｜双方参与聊天的不同单位。A，双方消息、文字字符和发言回合的占比；系统提示不计入双方消息。B，每回合消息条数的累计分布。C，以设定阈值划分的对话开启者与聊天日末条消息发送者。D，同段对话内发送者切换时的相邻回复间隔。对话阈值与聊天日分界采用本次配置中的设置。

最终图注应写出具体阈值与日界，避免让读者回配置文件查找。其他图同样交代好日期、计数口径和缺失情况。

## 把生活细节放到合适的位置

前言可以交代为什么想保存这段记录。结果部分围绕数据，个人片段放在能解释那个发现的地方。结尾和个人喜好页可以写想留下的习惯、愿望与祝福。

挑选短句时回原始 JSON 或 HTML 核对发送者、时间与上下文，并确认另一位参与者愿意保留。食物、城市和人物的提及次数只是文本记录；实际喜好、见面和旅行由双方补充确认。

## 讨论和摘要最后写

讨论从全文最主要的判断开始，把几组图联系起来：哪些维度一起变了，哪些保持稳定，有哪些背景可能解释这种组合。随后说明导出完整性、附件缺失、词典覆盖和单一双人档案带来的限制。

摘要保留观察窗口、记录规模、主要做法和两三项发现。不要把所有图的数字塞进去，也不要在摘要里增加正文没有支持的新结论。

写英文稿时，逐项核对日期、人数、单位、分母和图号。中英文可以调整句子顺序，但数值和含义要一致。若使用写作工具，提供必要的汇总和自己确认的背景即可；原始私聊不必整份交出去。

## 保持术语一致

| 中文 | English | 本项目中的含义 |
|---|---|---|
| 归档记录 | archive record | 包含系统提示 |
| 双方消息 | participant message | 排除系统提示 |
| 发言回合 | turn | 同一发送者的连续消息；新对话也开启新回合 |
| 对话 | conversation | 按消息间隔阈值划分 |
| 相邻回复间隔 | adjacent reply gap | 同段对话中发送者切换时的时间戳差 |
| 抽样范围 | sampling range | 等量消息抽样所得的敏感性范围 |
| 自述喜好 | reported preference | 由参与者提供的资料 |

## 修改后的排版

在稿件副本的 `latex/` 目录，用 XeLaTeX 编译两遍，英文稿同理。编译后检查每一页的图注、中文字体、长姓名和分页。图表轴名改动后，重新核对正文和图注是否仍然对应。完整命令见 [PDF 说明](PDF.md)。
