# 结果与讨论构件

自动文稿用于提供有数值依据的初稿，深度解读需要参与者核对语境后继续写作。以下约定是本项目自己的写作说明，没有打包第三方技能文件，也不是期刊官方要求。

## 一页回答一个问题

结果段落按“问题 → 关键比较 → 有限结论 → 下一问题”组织。建议从时间连续性进入参与单位，再到表达材料、渠道覆盖、词典边界，最后检验词汇结果是否受抽样影响。

关键证据应在结果中呈现。例如消息量不对称与回合接近时，把三种计数单位与比值分解放在一起；不要只列数字，让读者自己寻找差别。

## 讨论做综合

讨论从跨结果的判断开始，而不重播整套数字。把时序、参与和词汇看成不同维度，说明它们共同支持什么、尚未解释什么。文献背景、测量边界和可检验的后续工作各有位置；不能把关联改写成原因。

## 固定术语

| 中文 | English | 定义 |
|---|---|---|
| 归档记录 | archive record | 包含系统提示 |
| 双方消息 | participant message | 排除系统提示 |
| 发言回合 | turn | 同一发送者连续一组消息 |
| 对话 | conversation | 以沉默阈值划分 |
| 相邻回复间隔 | adjacent reply gap | 发送者切换时的时间戳差 |
| 抽样范围 | sampling range | 等量消息抽样得到的敏感性范围 |
| 自述喜好 | reported preference | 参与者提供，独立于词频 |

个人画像可以保留生活细节和愿望。请说明哪些是参与者自述，哪些是已确认事件，哪些是装饰或未来愿望。不要由家乡推定异地，由地名推定旅行，由食物词频推定实际用餐或喜好。
