# 方法、单位与限制

本实现针对一个双人、单应用导出档案作描述。默认没有网络请求、语言模型服务、自动解密或关系质量评分。

## 计数与时间

- **归档记录**包含系统提示；**双方消息**排除系统提示。
- **文字字符**只计算文字/引用回复自己的正文长度；媒体标记不计作文字量。
- 非系统消息间隔超过阈值开始新对话。默认阈值 3 小时，同时给出 1、3、6 小时的开启计数。
- 发送者切换或新对话开始新发言回合。所有非系统消息类型均可构成回合。
- 相邻回复间隔是同段对话中发送者切换前后的时间戳差；相同时间戳允许零秒，不测量已读和持续关注。
- 总体日历使用自然日并保留零记录日期。月度日均量以窗口内实际观察自然日为分母。聊天日最后一条采用默认 05:00 日界。

参与者消息数严格等于回合数乘以平均每回合条数。比值分解是会计式恒等关系，不解释行为成因，也不把回合相等解释为付出相等。

## 语言

内容词使用 jieba 默认分词，去网址、内置表情标签，取至少两个字符且不在示例停用词表中的词。中文单字虚词另在完整词元序列中计数。字典均为本项目独立编写的小型示例，不是参考仓库词典。

各月计算双方内容词频向量余弦。固定词表由整个观察窗口的合并内容词频选择，默认最低10次；之后，每月每人等量无放回抽样，统一样本量取配置上限与所有有效月份候选池最小值。仅一方有内容词的月份不计算相似度。默认200次抽样，演示为加快运行使用40次。结果记录实际可计算抽样数，无法计算时保持 `null`。

抽样的中间95%范围是敏感性描述，不是人际影响的因果置信区间。固定消息数与词表不能排除话题构成、重复内容、语境或共同生活安排的作用。

词语对比使用合并词频0.1倍的 Dirichlet 先验，合并出现至少5次后作加权对数优势比排序。它是相对使用排名，不是一组独立显著性检验。短句与话题按正文包含关系计数，一条消息可以命中多个类别。覆盖率必须与排名一起报告。

虚词匹配对八类比例使用 `1 - |pA-pB| / (pA+pB+0.0001)` 后取均值。双方很少或都不用的类别可能抬高指标。这是未经验证的小型词典示例，不是 LIWC 量表，也不预测感情质量。

## 情绪与其他渠道

探索性情绪默认关闭。开启后，示例词典命中数给出 `(positive-negative)/(positive+negative)`，没有命中保持缺失；不提供复杂否定、讽刺、语境或人工校准。前置回合分数为已评分消息均值，低于 -0.2 为负面指标；对每个回应者按日期整组重抽样1000次，比较相邻回复间隔的中位数差。少于两个有效日期或任一比较组没有观测时，不计算区间。区间包含零不能证明等效。

照片、视频、语音和表情在这里首先是消息类型。时长来自输入元数据，通话按会话标识去重；没有标识就不推定独立通话。不同渠道时长没有作时间重叠扣除。文件存在、原图分辨率、手机历史完整性、音频内容均未被本工具验证。

## 可复核性

每次输出保存输入 SHA-256、当次配置、去重数量、分母、随机种子、实际样本量与缺失信息。`summary.json` 不包含整段原文，但词频、日期、作者与画像仍可能敏感，默认整个输出目录不参与发布。
