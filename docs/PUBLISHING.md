# 发布与隐私边界

## 当前文件夹

公开文件在 `PUBLIC_FILES.json` 中逐一列出。当前交付只有代码、说明、模板、测试、合成样例和从合成样例绘制的预览图。没有真实聊天正文、个人附件、私人论文、账户标识、数据库密钥、缓存、第三方字体或角色插画。

`config.local.json`、`private/`、`data/`、`exports/`、`outputs/`、本地环境与数据库等已写入 `.gitignore`。**忽略规则不是网页上传规则**：浏览器仍可上传你手动拖进去的私人文件。

## 推荐流程

1. 私人输入、配置、图片放在忽略目录。
2. 输出留在 `outputs/`，不手工复制到 README 或截图里。
3. 修改公共代码后同步 `PUBLIC_FILES.json`。
4. 运行 `python scripts/audit_release.py`。
5. 运行 `python scripts/prepare_release.py --destination dist/github-ready`。
6. 检查新文件夹，然后将其中内容上传新建的 GitHub 仓库。

允许清单复制不会带上后来加入的原始数据或输出目录。审查脚本会阻止可识别的账户标识、私钥片段、本机绝对用户路径与不应分发的文件类型；这种模式扫描不能证明彻底匿名化，新增的文档内容仍需人工阅读。

如希望用 Git 命令推送，可在确认候选文件后自己初始化仓库、检查暂存清单并添加自己的远程地址。本工具不会替你公开发布。

## 公开结果需要单独决定

日期、词频、个人画像、通话数量、时长和生成的文章都可能包含私人信息，即使没有整段聊天正文。开源工具与公开个人结果是两件事。本项目默认只发布工具和合成数据；将来若要公开自己的结果，应由相关参与者决定范围。

第三方素材、商标角色、明星照片或字体不能因为进入一篇个人报告就自动获得再分发许可。默认公开模板没有捆绑这些素材。新实现的MIT许可不覆盖用户另行添加的内容或外部依赖。
